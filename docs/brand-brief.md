# MASTER PROMPT — ZUNO E-COMMERCE WEBSITE

## 1. Project Objective

Create a **premium, minimal, interactive and fully responsive e-commerce website** for **ZUNO**, based on the existing **Wix Studio "Supplements Store" template**.

### Critical instruction

**DO NOT redesign the website from scratch.**

The selected Wix Studio template must remain the **structural and interactive foundation** of the website. Preserve its:

* Overall layout logic
* Section structure where applicable
* Scroll behaviour
* Transitions
* Animations
* Interactive effects
* Visual flow
* Responsive behaviour

The goal is to **transform the existing template into the ZUNO brand**, not to replace the template with a generic website.

The transitions and interactive experience of the original template — especially in sections such as **About Us** — are an important part of the desired result and should be preserved as closely as technically possible.
